# 田园斗地主规则与引擎约定

本目录只包含纯游戏逻辑；房间锁、玩家身份、网络连接、请求幂等、修订号和豆数持久化由外层负责。

## 开局与阶段

- 一副 54 张牌，三人各 17 张，底牌 3 张。`0..51` 的点数是 `id/4+3`，`15` 表示 2；`52/53` 是小王/大王。花色为 `id%4`。手牌按点数、花色 ID 降序排列。
- 使用 Go `crypto/rand` 的 Fisher–Yates 洗牌。公开视图仅含请求玩家的手牌和其他人的剩余张数；底牌在地主确定前为 `[]`。
- 座位按 `0→1→2→0` 行动，外层指定首叫座位。每人叫分一次：0 不叫、1/2/3 分；非零必须高于已叫分。3 分立即结束叫分；否则三人叫完取最高分。
- 全员不叫时立即重新洗发，首叫座位轮转一位，同一 `roundId` 下继续；没有扣豆或结算。
- 地主取得底牌后，三人同时选择一次加倍或不加倍，限时 **10 秒**；未选择者默认为不加倍。加倍阶段 `turn=-1`。已托管者自动不加倍。
- 地主首先出牌。叫分每回合 **15 秒**，正常出牌每回合 **20 秒**。到时叫分自动不叫；跟牌自动过；领出自动出最小单牌。
- 托管的叫分/出牌延迟是 1 秒，同样遵守上述超时动作。开关托管不会延长该回合原来的截止时间（叫分 15 秒、出牌 20 秒）。进入加倍时托管玩家选择不加倍。
- 对服务器时间已到截止点的人工叫分、加倍、出牌请求拒绝；定时器负责下一状态。`Tick` 每次最多推进一个动作。

## 14 类牌型

| `kind` | 牌型 | 规则 |
|---|---|---|
| `single` | 单牌 | 3 最小，A＜2＜小王＜大王 |
| `pair` | 对子 | 两张同点数普通牌 |
| `triple` | 三张 | 三张同点数普通牌 |
| `tripleSingle` | 三带一 | 三张＋不同点数单牌 |
| `triplePair` | 三带一对 | 三张＋另一点数对子 |
| `straight` | 顺子 | 至少 5 个连续点数，最大 A |
| `pairStraight` | 连对 | 至少 3 对连续点数，最大 A |
| `airplane` | 三顺 | 至少 2 组连续三张，最大 A |
| `airplaneSingle` | 飞机带单 | 连续三张主体＋同组数单牌翼 |
| `airplanePair` | 飞机带对 | 连续三张主体＋同组数、不同点数对子翼 |
| `fourTwoSingle` | 四带二 | 四张同点数＋两张单牌 |
| `fourTwoPair` | 四带两对 | 四张同点数＋两个不同点数对子 |
| `bomb` | 炸弹 | 四张同点数 |
| `rocket` | 王炸 | 大王＋小王 |

- 飞机主体不能带 2 或王，主体每个点数恰好三张；同主体点数的第四张不能再作翅膀。
- 单牌翼允许形成对子，不允许凑成三张/炸弹，也不允许大小王同时作为翼。四带二允许带一对，但不允许同时带大小王。
- 对子翼必须来自不同点数，不能把同一炸弹拆成两对。四带两对也不能拿两副炸弹组成。
- 当选择同时可解释为三顺时优先按不带翼的三顺处理。
- 普通牌型必须同类型、同张数才能比较，比较主体最大点数，翼不参与大小。炸弹大于普通牌型，王炸最大；同一组合不能压自己。
- 两家连续过牌后，最后出牌者重新领出，可以出任意合法牌型；领出不能过牌。
- 提示枚举点数数量组合，去掉仅花色不同的等价组合，最多返回 64 组。能一次出完的选择排首位，普通压制优先于炸弹/王炸；所有提示仍经权威校验。

## 倍率与结算

- 固定底分 **100 豆**。`multiplier` 为叫分 × 炸弹/王炸倍数 × 春天倍数，独立于每人的加倍状态。
- 每次炸弹或王炸使公倍数 ×2；四带二等带牌组合不算炸弹。
- 地主赢且两个农民均未出过牌为春天；农民赢且地主只出过一手牌为反春。两者都使公倍数 ×2，并将 `settlement.spring` 置为 `true`。
- 地主与每个农民的理论输赢为 `100 × multiplier × 地主加倍系数 × 该农民加倍系数`，不加倍系数 1，加倍系数 2。任一农民出完牌表示农民阵营共同胜利。
- 每个输家的实付不超过其结算前余额；赢家不设与自身余额相关的收益上限。地主赢时两个农民分别扣款；地主输但余额不足时，按两个农民的理论收益比例分配其全部可用余额。
- 比例分配先向下取整，不足整豆的剩余按座位 0、1、2 的顺序分给符合条件的赢家。全过程整数运算、非负余额、严格零和。
- `Settle` 第一次结束后调用会缓存结果，再调用不会重复扣款，也不会采用后来传入的余额。返回值和视图均深拷贝。

## 外层接口

```go
New(roundID string, firstBidder int, nowMS int64) *Engine
(*Engine).Apply(seat int, action Action, nowMS int64) error
(*Engine).Tick(nowMS int64) bool
(*Engine).Hint(seat int) [][]int
(*Engine).View(seat int) GameView
(*Engine).Finished() bool
(*Engine).Settle(balances [3]int64) Settlement
(*Engine).Trustee(seat int) bool
```

所有时间戳为 Unix 毫秒。`bids` 的 -1 是未叫、0 不叫；`doubles` 的 -1 是未选择、1 不加倍、2 加倍。未确定地主/赢家为 -1。`lastPlay` 在重新领出时为 null；已出牌和过牌保存在 `history`，过牌 `kind="pass", cards=[]`。

`Apply` 检查座位、阶段、轮次、截止时间、重复牌 ID、持有牌、牌型和压制关系；被拒绝的普通动作不改变游戏状态。玩家身份与 seat 的绑定必须由外层进行，调用者不得使用客户端传入的任意 seat。

## 上游复用

Apache-2.0 项目 `dolotech/doudizhu` 的固定版本、许可证与修改说明见 `thirdparty/dolotech/NOTICE.md`。复用其位压缩点数统计和牌型比较；所有选牌先由本引擎独立分类。未复用原有重复牌校验和不严格的飞机/四带两对判断。

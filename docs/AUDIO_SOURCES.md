# 音乐与角色语音（公开首版 0.1.0）

## 随包音频

`assets/audio/garden-table.ogg` 是本项目新制作的原创器乐曲《田园牌局》。32 小节、104 BPM，约 74 秒，包含笛音主旋律、拨弦分解和弦、低音、轻打击乐与立体声空间尾音。旋律、编曲和合成器实现均在 `scripts/generate-audio.py` 中，不使用其他游戏的旋律、采样或录音。播放时只解码一次并用 Web Audio 缓冲循环，不再依赖逐音符的 JavaScript 定时器。

角色语音由 **Kokoro-82M-v1.1-zh** 在本地 CPU 上预渲染。插件只带 OGG 录音；没有上传用户语音，不需要 API 密钥、在线服务、运行时模型或系统中文 TTS。系统本地中文语音仅在音频解码失败时作为备用。

- [官方模型页及 Apache-2.0 标记](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)
- 固定模型修订：`01e7505bd6a7a2ac4975463114c3a7650a9f7218`
- [官方推理实现与许可证](https://github.com/hexgrad/kokoro)
- [上游中文生成示例](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh/blob/main/samples/make_zh.py)
- 许可证副本：`assets/licenses/kokoro-Apache-2.0.txt`

上游模型卡说明，中文训练数据由 LongMaoData 提供许可，包含 100 位中文说话人。本项目使用模型自带的中文音色向量，不克隆指定真人、明星或腾讯角色的声音。选择的音色为 `zm_009`、`zf_001`、`zm_010`、`zf_017`、`zm_014`，分别对应阿禾、小满、福伯、青竹、长安。语速、停顿、文本语气和常用语变体按场景处理，发声保留原音色，不通过大幅升降调制造角色差异。

这套声音是**神经合成角色语音，不是真人配音表演**。相比旧版现场调用系统 TTS，音色、音量、响应和离线可用性一致；若作为正式商业产品发布，仍建议由配音导演试听审核并补录关键情绪台词。

## 欢乐斗地主原声检索结果

已检索欢乐斗地主官方站、腾讯游戏协议、游戏原声和音乐发行资料。能找到原声的收听页面及玩家整理，但截至本次制作，没有取得能够把原声录音嵌入第三方插件再分发的明确授权。开源棋牌游戏仓库的代码许可证，也不能证明其夹带的腾讯音乐录音可以重新打包。

因此本包**未附带欢乐斗地主原声**。设置中的「更换音乐」允许导入用户有权使用的 MP3、OGG、WAV 或 M4A，最大 4 MiB、时长 1 秒至 10 分钟。音频存储在本机插件数据目录，重开工作台后恢复，不向房间其他玩家或任何互联网服务发送。点击「恢复原声」会恢复本项目原创音乐。

检索入口：[欢乐斗地主官网](https://hlddz.qq.com/)、[腾讯游戏许可及服务协议](https://game.qq.com/contract.shtml)。上述链接是来源核查记录，不代表获得腾讯授权。

## 播放与验收要点

- 五套角色音色，每套 72 段、合计 **360 段**。叫分、加倍、不出、单牌与对子点数、全部复合牌型、胜负、礼物与快捷语均有离线语音。
- 常用「不出」「三分」「加倍」「胜负」轮换不同台词；同一事件 ID 不重播，声音串行播放，音乐自动压低后平滑恢复。
- 重新连接、离开房间、切换到后台时清空旧台词，避免回来后补播陈旧动作。调整音量实时生效，角色选择可试听。
- `voice-manifest.json` 记录每段文本、路径、时长；生成报告包含峰值与 SHA-256。模型和 Python 虚拟环境都在工程外部，不进入安装包、源码包。

Chrome 实测：360 段全部成功解码，无静音和削顶；连续三段「不出」不重叠、重复事件不重播；异步加载中清队列不会补播旧动作；语音期间音乐压低并恢复；有效导入、过大文件和损坏文件拒绝、恢复原声均通过。报告在 `test-results/audio-v02/browser-report.json`，真实混音录音为同目录 `audio-mix-preview.webm`。这些是技术验收，不替代真人的表演质量试听。

复现使用 Python 3.12，安装固定版本的制作依赖后运行：

```sh
pip install -r scripts/audio-requirements.txt
python scripts/generate-audio.py --samples
python scripts/generate-audio.py
```

初次生成需要下载公开模型；插件游玩时不需要互联网。音频文件同时复制到 `assets/audio/`（DBX 资源接口）与 `public/assets/audio/`（本地开发预览）。

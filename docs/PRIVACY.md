# 联机范围与本地数据

田园斗地主是供三位玩家在本地局域网联机的 DBX 小游戏。房主自己的电脑临时托管房间，另外两台电脑通过局域网发现或手动地址加入。项目不运营公网大厅、匹配服务器、互联网账号系统或云存档服务。

## 无收费和兑换功能

没有充值、支付、内购、广告奖励、提现、兑换、玩家间转账或真钱下注功能。房间内的欢乐豆只是本局域网房间的计分数字，没有货币价值，不可购买、出售、兑现或跨房间转移。房间解散后计分余额清空。互动道具免费。

## 网络

- mDNS 使用 UDP 5353 广播房间名称、房号、人数、阶段、是否需密码及协议版本；不广播密码或手牌。
- 房主 Go 进程监听系统分配的 TCP 端口。已加入的客户端通过 TLS 发送准备、叫分、出牌和互动等游戏消息。
- 游戏没有运营方公网服务、遥测、广告请求、在线语音生成或外部素材下载。图像、字体、音乐和角色语音随包提供；断开互联网后仍可在局域网游戏。
- 手动直连支持用户填写的 host:port；它不是公网地址过滤器。请填写自己信任的局域网地址，不要把房间端口映射到公网。此边界说明不能被解读为软件从协议层绝不可能连接公网。
- 下载、更新插件及查看 GitHub 文档属于分发流程，不是游戏运行中的在线服务。

## 数据与权限

本机插件数据目录保存随机玩家身份及鉴权密钥、昵称、角色、音量和低动效偏好，以及用户主动导入的音乐。身份与偏好不会自动上传到互联网。已加入的房间需要共享玩家昵称、角色、身份标识与游戏状态；每人只能收到自己的手牌及公开的对手剩余张数。

音乐导入只读取用户选择的文件，最大 4 MiB，保存在本机且不向牌友发送。插件不读取 DBX 数据库连接、凭据、查询结果或其他插件的数据，不申请数据库或宿主二进制管理权限。Manifest 仅申请 `host.events`，用于工作台与自身 Go 后端交换事件。

后端是原生 Go sidecar，由 DBX 管理生命周期，不安装后台系统服务、不修改防火墙规则、不下载或启动额外运行时。网络监听随房间／插件进程关闭而结束。

# 本地开发版 0.2.0 验收记录

这是旧身份 `local.doudizhu` 的历史体验验证；公开首版 `io.dbx.doudizhu` 0.1.0 保留此版功能，发布身份与版本另经 tag CI 校验。本文件中的 0.1.0／0.2.0 均指开发包编号。

日期：2026-10-17。项目为独立 DBX 插件；没有修改 DBX 主程序或自动覆盖用户安装的 0.1.0。

## 版本范围

新增青竹、长安，角色总数为五名。修复肩臂接缝、左右臂绑定和重复背景，增加离线角色语音、单独音量、音乐导入、台词气泡及键盘操作。LAN 协议升为 2，三位玩家需要一起升级到 0.2.0。升级保留本机玩家身份与偏好。

左右手问题按各图集的实际手部方向修正：阿禾、小满、福伯、青竹交换整条手臂及其肩根／肘点配置；长安保留其正确绑定。动作检查包含拇指方向、袖口与肩肘连接。连通性检查只能发现分离的部件，不能证明解剖方向正确，因此另行查看五名角色的垂手、胜利、思考和倒茶画面。

官方开发宿主实际使用 `about:srcdoc`、`allow-scripts` 沙箱和 `connect-src 'none'`；未放宽安全设置。其体验验收未出现浏览器错误、失败的业务 HTTP 请求、外网请求或系统 TTS 回退。开发宿主自身 favicon 的 404 单独记录，不计作插件资源成功。

验收中发现三人同时点击加倍时，第一人的选择改变全局版本号，可能使后两人的合法选择被当成过期请求。现在仅对同一局、仍在加倍阶段且本人尚未选择的加倍动作允许并发提交；过期出牌、未来版本、其他牌局和重复改选仍拒绝。新增三并发回归测试，官方宿主中也验证了实际按钮点击。

## 声音与实际演示

`demo-30s.webm` 是官方开发宿主中实际渲染的角色和互动演示；浏览器录屏本身无音轨。`audio/audio-mix-preview.webm` 是 Web Audio 实际输出的独立混音录音。音频采用预渲染神经合成角色声音，并非真人配音。自动解码、峰值和播放顺序检查不等于完成了真人听觉审片。

随包音乐为本项目原创约 74 秒的器乐曲。没有取得腾讯《欢乐斗地主》原声可随第三方插件再分发的明确授权，因此没有打包该录音；本地音乐导入支持 MP3／WAV／OGG／M4A，最大 4 MiB。来源、模型许可与制作方式见 [AUDIO_SOURCES.md](AUDIO_SOURCES.md)。

## 验证边界

- 自动化联机使用同一台电脑上隔离的真实进程，不能视为三台物理电脑的局域网验证。真实路由器、多机防火墙和无线隔离需要现场环境。
- 官方开发宿主沿用实际资源桥接与沙箱，但不是用户安装的桌面 DBX。此前已与用户在已安装的 0.1.0 中完成一局；该结果不冒充 0.2.0 的桌面实测。
- 浏览器完整对局测试使用软件 WebGL，其 RAF 频率不能代表原生 GPU 游戏帧率。原生 GPU 演示的采样与资源情况以对应 metadata 为准，不把录屏帧率视为渲染 FPS。
- 尚未做大量硬件兼容性、长时间多日稳定性或正式商业发行的人工表演审片。本次是具备源码、开发安装包和可复验证据的体验改进版。
